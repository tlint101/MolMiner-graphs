# Dataset
This folder contains dataset for use with the tutorials. The information was pulled from [MoleculeNet](https://moleculenet.org). 
The dataset is the same as can be found from their repository, with the exception of adding additional train/test labels 
for cross-validation and replacing the default splits with a random split. All splits were done using the random 
parameter. As of this writing, there contains the dataset for:

BACE Quantitative (IC50) and qualitative (binary label) binding results for a set of inhibitors of human β-secretase 1(BACE-1).
